03. Proprietary Fit Architecture

Proprietary ingestion. Deterministic geometry.

The scraper reads a product page and classifies reviews with deterministic rules. Fit numbers are stored per size. A separate comparison engine measures a candidate against a garment the shopper already owns. Missing measurements stay blank.

  1. 01. Ingest

    Read the reviews on a product page

    The scraper loads the page and classifies each review by size, fit direction, shrinkage, and sentiment.

  2. 02. Store

    Keep the numbers

    Each size gets a row: review count, fit skew, verdict, and shrinkage mentions. Full review text stays on the machine that scraped it.

  3. 03. Compare

    Measure against an owned garment

    The comparison engine scores the sizes it has measurements for. A missing centimeter stays empty.

  4. 04. Replace

    A later scrape updates that SKU

    Scraping the same SKU again replaces its size rows in the shared table. It does not add a second copy.

Missing measurements stay blank. The comparison engine leaves an unknown centimeter empty. The match score in the sample above is a separate illustration on this page.

06. Frequently Asked Questions

Answers for brands and partners

What data does Pearfit need to launch a pilot?

Product page URLs. The scraper reads the reviews on those pages and stores numerical fit values per size. Full review text stays on the machine that scraped it. A size chart on the page is stored with those fit rows. A measurement the chart does not state stays blank.

How do shoppers tell Pearfit what clothes they already own?

The sample on this page lets you pick one of four reference shirts. Comparing a real catalog with clothes a shopper owns is the separate comparison engine. This page does not store that choice.

How does Pearfit’s proprietary engine work without LLMs?

The scraper classifies review text with deterministic rules and stores the resulting numbers. When a measurement is missing, it stays blank. The sample score on this page is an illustration, separate from the comparison engine.

How do you measure ROI during the 6-week pilot?

The calculator on this page is a model you fill in. A pilot would compare your own fit-return rate before and after, using your orders.

How is shopper privacy handled?

The sample on this page stores nothing. The scraper keeps review text on the machine that scraped it. The shared database receives the fit numbers.
